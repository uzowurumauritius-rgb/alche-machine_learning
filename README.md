# alche-machine_learning

Repository for Machine Learning curriculum projects at ALCHE (Holberton School).

## Content
- `math/advanced_linear_algebra`: Advanced linear algebra (determinant, minor, cofactor, adjugate, inverse, definiteness)
- `math/calculus`: Calculus (summations, products, derivatives, partial derivatives, integrals, polynomial differentiation and integration)
- `math/linear_algebra`: Linear algebra operations in Python and NumPy
- `math/plotting`: Matplotlib plotting tasks
