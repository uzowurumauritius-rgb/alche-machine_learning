# ALCHE Machine Learning - Calculus

This directory contains solutions for the **Calculus** project in the **Mathematics for Machine Learning** module at ALCHE / Holberton School.

## Tasks

| File | Description |
| --- | --- |
| `0-sigma_is_for_sum` | Summation expansion evaluation |
| `1-seegma` | Double-variable summation evaluation |
| `2-pi_is_for_product` | Product notation factorial identity |
| `3-pee` | Zero-indexed product notation evaluation |
| `4-hello_derivatives` | Polynomial derivative calculation |
| `5-log_on_fire` | Product rule derivative of `x ln(x)` |
| `6-voltaire` | Chain rule derivative of `ln(x^2)` |

| `11-integral` | Indefinite power-rule integral |

| `13-definite` | Definite polynomial integral |
| `14-definite` | Improper integral convergence check |
| `15-definite` | Definite integral with respect to `dy` |
