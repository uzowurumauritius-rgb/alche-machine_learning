# ALCHE Machine Learning - Plotting

This directory contains solutions for the **Plotting** project in the **Mathematics for Machine Learning** module at ALCHE / Holberton School.

## Tasks

| File | Description |
| --- | --- |
| `0-line.py` | Plots $y = x^3$ as a red line graph from $x \in [0, 10]$ |
| `1-scatter.py` | Plots height vs weight as a magenta scatter plot |
| `2-change_scale.py` | Plots exponential decay of C-14 with logarithmic y-axis |
| `3-two.py` | Plots exponential decay of C-14 and Ra-226 with legend |
| `4-frequency.py` | Plots histogram of student grades with bins every 10 units |
| `5-all_in_one.py` | Combines all 5 previous plots into a 3x2 grid layout |
| `6-bars.py` | Plots a stacked bar graph of fruits per person |
