# ALCHE Machine Learning - Linear Algebra

This directory contains solutions for the **Linear Algebra** project in the **Mathematics for Machine Learning** module at ALCHE / Holberton School.

## Tasks

| File | Description |
| --- | --- |
| `0-slice_me_up.py` | Slices a 1D list in Python |
| `1-trim_me_down.py` | Extracts middle columns of a 2D list |
| `2-size_me_please.py` | Calculates the shape of a nested list matrix |
| `3-flip_me_over.py` | Computes the transpose of a 2D matrix |
| `4-line_up.py` | Adds two 1D arrays element-wise |
| `5-across_the_planes.py` | Adds two 2D matrices element-wise |
| `6-howdy_partner.py` | Concatenates two 1D arrays |
| `7-gettin_cozy.py` | Concatenates two 2D matrices along axis 0 or 1 |
| `8-ridin_bareback.py` | Performs 2D matrix multiplication |
| `9-let_the_butcher_slice_it.py` | Slices a 2D NumPy array |
| `10-ill_use_my_scale.py` | Returns the shape of a NumPy array |
| `11-the_western_exchange.py` | Transposes a NumPy array |
| `12-bracin_the_elements.py` | Performs element-wise arithmetic on NumPy arrays |
| `13-cats_got_your_tongue.py` | Concatenates two NumPy arrays along an axis |
| `14-saddle_up.py` | Performs matrix multiplication using NumPy |
